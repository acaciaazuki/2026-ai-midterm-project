# 貪食蛇網頁遊戲：技術棧與實作計畫

> 學校期中專題，預計 2026 年 10 月底前完成。

## 一、技術棧

| 項目 | 決定 |
|---|---|
| 語言 | 原生 JavaScript（ES Modules），不使用框架 |
| 繪圖 | HTML5 Canvas 2D |
| 樣式 | 純 CSS，介面配色使用 CSS 變數，跟著主題切換 |
| 建置工具 | 不使用，原始碼即部署檔案 |
| 測試 | 本階段不加入 Vitest，但邏輯與畫面分離，之後可隨時補上 |
| 多國語言 | 台灣正體中文、英文，自製字典模組 |
| 本機儲存 | `localStorage`：最高分、語言、主題、上次的設定 |
| 字型 | 以系統字型為主；像素風主題選用「俐方體11號（Cubic 11）」子集 |
| 本機開發 | VS Code Live Server 或 `npx serve` |
| 部署 | GitHub Pages（之後可改用 Cloudflare Pages） |

### 程式碼規範

- 註解、文件、commit 訊息、介面預設文字一律使用台灣正體中文。
- 變數、函式、檔案名稱使用英文命名。
- 縮排 2 格，使用 UTF-8 編碼。
- 語言檔使用 `.js` 而非 `.json`，以便撰寫註解並直接 `import`。

## 三、功能規格

### 3.1 遊戲模式與難度

關卡分為「經典」（無障礙物）與「隨機」兩種，搭配三種難度，共六種組合，最高分分開記錄。

| 難度 | 初始速度 | 加速規則 | 隨機關卡障礙物 |
|---|---|---|---|
| 簡單 | 慢 | 不加速 | 約 3% 的格子 |
| 普通 | 中 | 每吃 5 個加速一次 | 約 6% |
| 困難 | 快 | 每吃 3 個加速一次 | 約 10% |

所有數值集中於 `config.js`，實際遊玩後再調整。

### 3.2 穿牆規則

上下邊界與左右邊界分開決定能否穿越，共四種組合：

| 規則 | 說明 |
|---|---|
| 全部可穿越 | 上下、左右都能穿到另一側 |
| 只能上下穿越 | 上下相通，左右兩側是牆 |
| 只能左右穿越 | 左右相通，上下兩側是牆 |
| 全部是牆 | 撞到任何邊界即結束 |

**經典模式**：簡單為「全部可穿越」，普通與困難為「全部是牆」。

**隨機關卡**：由種子亂數依難度機率決定。

| 難度 | 全部可穿越 | 只能上下 | 只能左右 | 全部是牆 |
|---|---|---|---|---|
| 簡單 | 60% | 20% | 20% | 0% |
| 普通 | 20% | 25% | 25% | 30% |
| 困難 | 10% | 20% | 20% | 50% |

- 每關開始前顯示本關規則約 1.5 秒，遊戲中在分數旁顯示小圖示。
- 每個主題都必須清楚畫出可穿越的邊界與牆壁的差別。

### 3.3 隨機關卡生成

- **種子亂數**：同一組種子碼產生同一張地圖與穿牆規則；畫面顯示關卡代碼，可輸入代碼重玩或分享。
- **保證走得通**：生成障礙物後以 BFS 檢查所有空格皆連通（可穿越的邊界視為相連），未通過則重新生成。
- **出生點保護**：蛇的初始位置與前方數格不放置障礙物；若前方是不可穿越的牆，需保留足夠距離或改變出生方向。

### 3.4 操作方式

- 鍵盤：方向鍵或 WASD 移動，空白鍵暫停，Enter 開始或重來。
- 手機：於遊戲區域滑動控制方向。
- 輸入佇列最多暫存 2 個方向，防止快速連按時回頭撞到自己。

### 3.5 遊戲迴圈

使用 `requestAnimationFrame` 搭配固定更新間隔，確保不同螢幕更新率下遊戲速度一致。

### 3.6 畫面流程

```
主選單 → 遊戲中 ⇄ 暫停
           ↓
        遊戲結束 → 再玩一次／回主選單
```

主選單可選擇關卡模式、難度、主題、語言，並可輸入種子碼。

### 3.7 主題系統

每個主題檔案提供：

- Canvas 用的配色
- 介面用的 CSS 變數
- 繪圖函式：背景、邊界（含穿牆標示）、蛇頭、蛇身、食物、障礙物

像素風主題關閉 Canvas 圖片平滑處理，保持清晰的像素邊緣。

| 主題 | 視覺特色 |
|---|---|
| 簡約扁平 | 圓角方塊、柔和配色，支援淺色與深色 |
| Nokia 懷舊 | 淡綠液晶底、深色方塊、細格線 |
| Game Boy 四色 | 只用四種綠色，像素顆粒感 |
| 霓虹賽博 | 黑底、發光螢光線條、蛇身光暈 |
| 復古像素 8-bit | 紅白機配色，蛇頭有眼睛，像素蘋果 |
| 手繪筆記本 | 方格紙背景、鉛筆筆觸、塗鴉風格食物 |
| 高對比無障礙 | 高對比配色，以形狀區分物件 |

### 3.8 多國語言

- 首次開啟時，瀏覽器語言為 `zh` 開頭則使用正體中文，其餘使用英文。
- 選擇後存入 `localStorage`。
- 切換語言時同步更新 `<html lang>`。

### 3.9 無障礙

- 高對比主題以形狀區分物件，不只依賴顏色。
- 選單可完全以鍵盤操作。
- 分數變化與遊戲結束透過 `aria-live` 通知螢幕閱讀器。
- 系統開啟「減少動態效果」時，關閉霓虹主題的閃爍動畫。
