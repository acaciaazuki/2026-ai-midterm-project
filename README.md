# 貪食蛇網頁遊戲

學校期中專題：以原生 JavaScript 與 HTML5 Canvas 製作的貪食蛇網頁遊戲。不使用框架、不需要建置，瀏覽器直接執行。

**線上試玩**：<https://yuqi-cai.github.io/2026-ai-midterm-project/>

## 特色

- **兩種關卡模式**：經典模式（沒有障礙物）與隨機關卡（障礙物、穿牆規則每關不同）
- **三種難度**：速度、加速規則、障礙物數量與穿牆機率都不同
- **關卡代碼**：每張隨機地圖都有代碼，輸入代碼就能重玩或分享同一關
- **七種畫面風格**：從簡約扁平到霓虹、像素、手繪，連瀏覽器分頁的圖示都會跟著換
- **台灣正體中文與英文**：依瀏覽器語言自動選擇，也可以手動切換
- **鍵盤與觸控**：電腦用鍵盤，手機在遊戲畫面上滑動
- **無障礙設計**：高對比主題、完整鍵盤操作、螢幕閱讀器朗讀、尊重「減少動態效果」設定

## 操作方式

| 動作 | 鍵盤 | 觸控 |
|---|---|---|
| 移動 | 方向鍵或 W／A／S／D | 在遊戲畫面上滑動（不放開手指也能連續轉彎） |
| 暫停／繼續 | 空白鍵、P 或 Esc | 點分數列右邊的暫停按鈕 |
| 選單操作 | Tab 移動焦點，Enter 或空白鍵確認 | 直接點選 |

切換到其他分頁時，遊戲會自動暫停。

## 遊戲規則

### 模式與難度

| 難度 | 初始速度 | 加速規則 | 隨機關卡障礙物 |
|---|---|---|---|
| 簡單 | 慢 | 不加速 | 約 3% 的格子 |
| 普通 | 中 | 每吃 5 個加速一次 | 約 6% |
| 困難 | 快 | 每吃 3 個加速一次 | 約 10% |

最高分依「模式 × 難度」共六種組合分開記錄。

### 穿牆規則

地圖四周的邊界可能是牆，也可能可以穿到另一側。上下與左右分開決定，共四種：

| 規則 | 說明 | 畫面上的樣子 |
|---|---|---|
| 全部可穿越 | 上下、左右都能穿到另一側 | 四邊都是虛線 |
| 只能上下穿越 | 從上邊出去會從下邊進來，左右是牆 | 上下虛線、左右實線 |
| 只能左右穿越 | 從左邊出去會從右邊進來，上下是牆 | 左右虛線、上下實線 |
| 全部是牆 | 撞到任何邊界就結束 | 四邊都是實線 |

- **經典模式**：簡單為「全部可穿越」，普通與困難為「全部是牆」
- **隨機關卡**：依難度隨機決定，難度越高越容易遇到牆

| 難度 | 全部可穿越 | 只能上下 | 只能左右 | 全部是牆 |
|---|---|---|---|---|
| 簡單 | 60% | 20% | 20% | 0% |
| 普通 | 20% | 25% | 25% | 30% |
| 困難 | 10% | 20% | 20% | 50% |

每關開始前會顯示本關的規則，遊戲中分數列旁也有小圖示提示。

### 關卡代碼

隨機關卡的代碼格式為「難度字母-六碼」，例如 `N-4F7K2Q`（E 簡單、N 普通、H 困難）。

- 遊戲中顯示在分數列，遊戲結束畫面也看得到
- 在主選單選「隨機關卡」後輸入代碼，就能玩到完全相同的地圖、穿牆規則與食物出現順序
- 大小寫、連字號都可以省略
- 遊戲結束時按「再玩一次」重玩同一關，按「新關卡」換一張新地圖

## 本機執行

本專案使用 ES Modules，必須透過本機伺服器開啟，無法直接雙擊 `index.html`。

擇一即可：

```bash
# 使用 Python
python3 -m http.server 8000

# 使用 Node.js
npx serve .
```

再用瀏覽器開啟 `http://localhost:8000`（使用 `npx serve` 時依終端機顯示的網址）。

也可以在 VS Code 安裝 Live Server 擴充功能，對 `index.html` 按右鍵選「Open with Live Server」。

### 清除遊戲資料

專案沒有建置產物，刪除專案資料夾就能清除所有檔案。不過下列資料存在其他地方：

- **最高分與設定**：存在瀏覽器的 `localStorage`，到瀏覽器設定中刪除 `localhost` 的網站資料即可清除
- **`npx serve` 的快取**：使用 `npx serve` 時，npm 會把套件下載到使用者目錄的快取中；使用 Python 或 Live Server 則沒有


## 技術重點

- **邏輯與畫面分離**：`snake.js`、`level.js`、`game.js` 只處理格子座標，不碰 DOM 與 Canvas；畫面全部交給 `renderer.js` 與主題
- **固定更新間隔的遊戲迴圈**：`requestAnimationFrame` 搭配時間累積，不同螢幕更新率下速度一致
- **輸入佇列**：最多暫存兩個方向，並和佇列最後一個方向比較，防止快速連按時回頭撞到自己
- **種子亂數**：使用 mulberry32 演算法，同一組種子永遠產生同一張地圖，關卡代碼因此可以重現
- **地圖連通檢查**：隨機產生障礙物後，用 BFS 確認所有空格都連得到（可穿越的邊界視為相連），不會出現困住食物的死路
- **出生點保護**：蛇的初始位置與前方幾格不放障礙物
- **主題系統**：每個主題提供配色、介面 CSS 變數與繪圖函式，新增主題不需要修改遊戲邏輯
- **多國語言**：語言檔集中管理所有文字，HTML 以 `data-i18n` 屬性標記，切換時同步更新 `<html lang>` 與網頁標題
- **高解析度繪圖**：Canvas 解析度依裝置像素比調整，手機上不會模糊
- **儲存容錯**：無痕模式或瀏覽器封鎖 `localStorage` 時，改存在記憶體中，遊戲照常運作
